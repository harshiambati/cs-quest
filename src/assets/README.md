# Custom rider image

Drop an image named `rider` into this folder and it replaces the default
cloud-whale rider at the front of the XP bar. Supported: `rider.png`, `rider.svg`,
`rider.webp`, `rider.gif`, `rider.jpg`.

Tips:
- Use a transparent background (PNG, SVG or WebP).
- Draw it facing right, so it looks like it is flying toward the flag.
- Roughly 3:2 works best. It is shown about 56px tall and scales to fit.
- Only use art you made or have the right to use. Do not commit images you
  do not have rights to if you make the repo public.

Remove the file to go back to the default rider.
